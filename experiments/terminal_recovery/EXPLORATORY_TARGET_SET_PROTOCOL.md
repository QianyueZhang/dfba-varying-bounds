# Exploratory continuous-target set analysis

Declared after seeing the complete 18-root dense target map and while nested-grid/deployment checks are still in progress. The fixed-target primary campaign is retained without relabeling. Its 108 targets are not replaced by successful targets selected here. This addition is explicitly exploratory.

Motivation: the primary 0.00748 log-ratio tolerance and designed uncertainty leave narrow admissible target sets, largely missed by the six fixed targets. Rather than selecting successful examples from the map and presenting them as prospective efficacy, compute the entire union of admissible **target intervals** for each saved 21-action transition tree. This involves no new integration, no controller tuning, and no widening of the band.

For every last-stage action with terminal log-ratios z_k, the admissible log-target interval is [max_k z_k - delta, min_k z_k + delta], when nonempty. For a given first action, take the union over continuation actions at each observed successor, then intersect these unions across first-stage disturbances. Finally union over first actions. All unions/intersections are closed and computed without merging disjoint intervals by an arbitrary tolerance. The robust common-open set is the union over two-feed plans of their all-nine-path target intervals. For the computed finite model, the open set must be contained in the causal set. These are target sets, not exact ODE state-reachability enclosures or continuous-uncertainty guarantees.

Save every component endpoint, total log-target length, total ratio-target length, matched-volume results, and the open/feedback set difference. Independently verify an economic policy and a filtered policy at the midpoint in log space of **every connected feedback component** for all nine paths. These midpoint witnesses are selected from the computed sets; their success fraction is a consistency check, not an unbiased validation score. Keep failed checks. If midpoint count is too large, save all components first and amend a deterministic coverage rule explicitly before deployment; do not sample based on outcome.

Also compute the target sets for 11 and 41 raw actions in the same six uniform-history roots; this is exploratory extension of the predeclared grid-sensitivity subset. Wider grids remain restricted action alphabets, not continuous-control certificates. Independent state comparisons use the existing 1e-7 log-ratio and 2e-7+2e-8 relative amount thresholds. Compare deployed witnesses to the outer band separately from the stricter inner decision margin.

All scientific comparisons will retain prior negative public-data outcomes and the failed earlier 440-episode numerical audit. No general speed, biology-validation, or journal-acceptance claim is authorized by this analysis.
