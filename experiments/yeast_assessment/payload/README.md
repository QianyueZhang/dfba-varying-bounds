# Yeast-assessment calculation payload

This directory supplies the exact calculation paths required by the study protocols. Use the parent directory's `run.py` and README for verification, figure generation and isolated workspace preparation. `run_study.py` executes a specified study in a new workspace; `verify_records.py` checks stored numerical evidence. Exact metabolic-model inputs are excluded and identified in `INPUT_MANIFEST.json`.

The `paper1_improvement_2026-10-24/manuscript/data/` and `manuscript/figures/` directories contain plotting assets, not manuscript drafts. No document TeX, Word, compiled paper or Overleaf package is included. Bibliographic and licence information is retained in `THIRD_PARTY_NOTICES.md`.
