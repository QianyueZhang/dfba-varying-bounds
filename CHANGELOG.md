## 0.4.0 — 23 October 2026

This version is published as a release snapshot of the research software. The release date identifies this software package; it does not date the start of the research.

- Fifteen Python simulation and analysis workflows cover moving-bound finite-barrier and differentiated KKT calculations, monocultures, microbial interactions, genome-scale communities, feed optimisation and neural surrogate models.
- The constrained biomass/composition study includes grouped datasets, five methods across twelve target cases and three seeds, all 180 policy records, JSON surrogate coefficients, direct-check records, sensitivity calculations and figure generation.
- Numerical tables, selected trajectories and attributed experimental observations are supplied with pinned requirements, command runners, software citation metadata, data dictionaries and verification instructions.
- Exact model dependencies are identified by case and SHA-256 hash. The 38 model-input paths are excluded pending source-specific distribution clarification; the input guide distinguishes self-contained table-based studies from calculations requiring these files.
- Documentation describes the mathematical problems and operating conditions directly. Source-record hashes remain available for relevant private implementation records; the distributed package requires no historical executable sources.
- The MIT Licence applies to author-owned source and documentation; experimental observations, external models and dependencies retain their own terms. Manuscript drafts, credentials and installed dependencies are excluded.

The release snapshot preserves the numerical equations, parameters and stored results. Documentary and source-record wording changes do not establish new numerical or biological validation.
